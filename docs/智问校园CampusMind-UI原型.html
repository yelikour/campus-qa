RAG 链路

问题 → 混合检索(BM25 ∥ 向量)→ RRF 融合 → 重排序(实验开关)→ 流式生成(SSE)→ 引用溯源

② 交互标注说明(对应界面中的红色编号)

  1. 品牌与产品名 —— 固定标识;侧栏底部实时显示引擎状态(向量 Provider 与索引版本,如实展示)。
  2. 三视图导航 —— 智能问答 / 知识库管理 / 运行看板,单页应用内切换,不刷新页面。
  3. 引擎状态徽标 —— 「RAG 引擎在线 · 向量 local-tfidf · 索引 v7」:演示环境如实标注 TF-IDF 非语义嵌入。
  4. 顶栏引擎信息 —— 知识库规模、当前 LLM 与索引版本;云端切换/降级时实时更新。
  5. 快捷问题 —— 一键代填典型校园问题,降低首次使用门槛;点击后走完整问答流程。
  6. 输入区 —— 回车或按钮发送;限流(429)时输入区上方出现提示气泡;流式回答期间发送按钮禁用。
  7. 知识库工具栏 —— 分类筛选 + 关键词搜索 + 新增表单(折叠);设置 ADMIN_TOKEN 后提交需管理令牌。
  8. 知识卡片与热更新 —— 录入提交后提示「已新增 n 条,索引热重建 v+1」,新知识立即可被检索命中,无需重启。
  9. 运行看板 —— 命中率/时延/热点分类实时聚合自查询日志;数字与数据库口径一致,可刷新。
③ 状态设计四类关键系统状态在界面上的呈现(原型内为静态样例,真实实现见 frontend/app.js)
