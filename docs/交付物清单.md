## 三、如何运行与验证(无需任何 API Key)

```bash
# 解压 05/CampusMind-source.zip 后:
python -m venv .venv && .venv/Scripts/pip install -r backend/requirements.txt
cd backend && ../.venv/Scripts/python -m uvicorn app.main:app --port 8000
# 浏览器打开 http://127.0.0.1:8000(顶栏显示引擎信息与索引版本)

# 验证(另一终端,于仓库根目录):
.venv/Scripts/python -m pytest backend/tests -q        # 14 passed
.venv/Scripts/python scripts/eval_matrix.py            # 四路评测
.venv/Scripts/python scripts/acceptance.py             # 需先启动服务,4/4 PASS
.venv/Scripts/python scripts/bench.py retrieval|e2e    # 性能基准
```

可选配置:`ZHIPUAI_API_KEY`(云端 GLM+语义向量)、`ADMIN_TOKEN`(知识写接口鉴权)、`RERANK_ENABLED=1`(重排实验)。
